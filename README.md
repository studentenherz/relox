# ReLox

This is an implementation of a bytecode interpreter for the Lox programming language form the [Crafting Inerpreters](https://craftinginterpreters.com) book. This tries to follow the while also attempting to write the interpreter using idiomatic Rust patterns and features.

> [!NOTE]
>  _ReLox_ could mean
>  - Rust Enhanced <a href="https://craftinginterpreters.com/the-lox-language.html">Lox</a> interpreter.
>  - Re-implementation of a Lox interpreter.
>  - Or you could read it like _reloj_, Spanish for clockwork, because that's how `this` should run like.
